# Vyntra AI – AI-Powered Document Assistant

## 📌 About the Project

Vyntra AI is an AI-powered document assistant that helps users interact with business documents using natural language. Instead of manually searching through documents, users can ask questions and receive relevant answers through an AI chatbot.

The project aims to make document search faster, easier, and more efficient.

## 🎯 Problem Statement

Businesses often store important information in documents, making it time-consuming to find specific answers. Vyntra AI addresses this challenge by providing an interactive assistant that helps users retrieve information from documents.

## ✨ Key Features

* 📄 Document-based information retrieval
* 💬 Interactive AI chatbot
* 🤖 AI-generated responses using Google Gemini
* 🗂️ Document processing functionality
* 💾 Database integration
* 🖥️ User-friendly interface built with Streamlit

## 🛠️ Technology Stack

* **Programming Language:** Python
* **Frontend:** Streamlit
* **AI Integration:** Google Gemini API
* **Database:** SQLite
* **Document Processing:** Python
